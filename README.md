# Java Advanced Program: Homework

Homework solutions for the Java Advanced program, grouped by module.
Each module lives in its own folder and is submitted as a separate Pull Request.

| Module | Folder | Status |
|---|---|---|
| Spring Boot | [`spring-boot`](spring-boot) | in progress |
| gRPC | `grpc` | planned |
| Reactive Programming | `reactive-programming` | planned |
| Security | `security` | planned |

## Conventions

- One task = one folder inside the module folder = one commit.
- One module = one branch (`module/<name>`) = one Pull Request.
- Every task is an independent Maven project that builds with `mvn verify`.
- Stack: Java 17, Maven.
